## Criteria

1. **Technical contribution** — code written, bugs fixed, difficulty of the work taken on
2. **Reliability** — met agreed deadlines, kept commitments to the group
3. **Collaboration** — communicated, reviewed others' work, helped when asked
4. **Documentation and testing** — README, diagrams, tests, commit messages
5. **Presentation** — preparation and delivery of their part of the demo
